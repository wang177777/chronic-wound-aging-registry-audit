# Exact-data boundary

The public code release does not redistribute the 1,218 complete ClinicalTrials.gov JSON records because some registry versions can contain contact modules. The NCT/hash manifest identifies each frozen record used by the validated analysis. Validated derived tables, figure data, numerical registers and change ledgers are included.

For byte-exact reruns, recreate the explicit paths and hashes in `manifests/ANALYTICAL_INPUT_MANIFEST.csv`. A newly downloaded current registry version may differ from the frozen source and should not be called a byte-identical reproduction.
